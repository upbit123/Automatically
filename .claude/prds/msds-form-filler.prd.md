# MSDS 양식 변환기

## Problem
KOSHA 형식의 MSDS 엑셀 파일(A문서) 내용을 기업 제출용 MSDS 양식(B문서)으로 옮기는 일을 한 사람이 손으로 하고 있다. 내용을 옮기면서 양식이 깨지지 않게 맞추느라 한 건에 6시간 이상이 걸린다. 사람이 수백 개 항목을 옮기므로 누락과 오기 위험도 있다.

## Evidence
- 사용자 진술: 수작업으로 한 건에 6시간 이상 걸리며, 대부분 양식을 맞추는 데 든다.
- 예시 A문서(`Mix_MSDS.xls`) 확인 결과: 시트 1개, 662행 × 5열, 병합 셀 581개, 값이 든 칸 403개. MSDS 표준 16개 항목 구조이고 한 항목이 여러 행에 걸친다.
- 예시 B문서(`WONDERCLEAN 800 (MSDS)` PDF, 12쪽) 확인 결과: 한글(Hwp 2020)로 만든 흐름형 문서. 쪽마다 머리글, 회색 띠 항목 제목, 중간에 표가 있다. 1~3쪽만 자세히 확인했고 4~12쪽은 표 개수만 확인했다.
- 두 예시 파일은 서로 짝이 아니다(같은 제품의 변환 전·후가 아님). 같은 제품의 A·B 쌍으로 검증한 적은 아직 없다 — Assumption, 실제 쌍으로 검증 필요.

## Users
- **Primary**: 사용자 본인 1명. A문서를 받아 제출용 MSDS를 만들어야 할 때 자기 맥에서 한 번에 한 건씩 실행한다.
- **Not for**: 다른 직원, 여러 사람이 함께 쓰는 환경, 여러 파일을 한꺼번에 처리하는 용도.

## Hypothesis
We believe **A문서의 내용을 B 양식에 자동으로 채워 PDF까지 만들어 주는 프로그램**이 **양식 맞추기에 드는 6시간 이상의 수작업**을 **MSDS를 작성해 제출하는 사용자 본인**에게서 없애 줄 것이다.
We'll know we're right when **A문서의 내용이 빠짐없이 들어가고 양식이 깨지지 않은 B문서 PDF가 10분 이내에 나온다**.

## Success Metrics
| Metric | Target | How measured |
|---|---|---|
| 내용 완전성 | A문서에서 값이 있는 항목이 100% 결과물에 들어감 | A문서의 값 목록과 결과물의 텍스트를 항목별로 자동 대조 |
| 양식 보존 | B 원본 양식과 비교해 깨진 곳 0건 (머리글, 항목 제목 띠, 들여쓰기, 표, 쪽 넘김) | 결과 PDF를 원본 양식과 나란히 놓고 사용자가 눈으로 확인. 세부 점검 목록은 TBD — 원본 .hwp 수령 후 작성 |
| 소요 시간 | 10분 이내, 빠를수록 좋음 | 프로그램 실행 시간만 잰다: A문서를 넣고 실행한 시점부터 PDF가 나올 때까지. 사람 검수 시간은 포함하지 않는다 |

## Scope
**MVP** — KOSHA 형식의 A문서 1개를 넣으면, B 양식에 A의 값을 그대로 채운 PDF 1개가 나온다.

- 모든 기준은 A문서다. 값은 A문서에 있는 그대로 넣는다. 문구 다듬기, 함유량 범위 변환, 물질명 번역은 하지 않는다.
- "자료없음"도 A문서에 적힌 그대로 옮긴다.
- 예시 B문서에 들어 있는 값(회사 정보, MSDS 번호, 버전·날짜 등)은 예시일 뿐이다. 결과물에는 A문서에서 온 값만 들어가고, 프로그램이 따로 입력받거나 저장해 두는 값은 없다.
- 내용이 길거나 항목 수가 많으면 B 양식의 행을 늘린다. 내용을 자르지 않는다.
- A문서는 매번 예시와 비슷한 형식이지만 완전히 같지는 않을 수 있다.
- B 양식은 한글 원본을 직접 고칠 수 없으면 Word 문서로 옮겨서 쓴다(사용자 동의).
- 변환 방식은 AI API가 아니라 정해진 규칙으로 동작하는 프로그램으로 한다. 같은 입력이면 항상 같은 결과가 나와야 한다.

**Out of scope**
- AI를 이용한 내용 해석·요약·번역 — MSDS는 값이 바뀌면 안 되는 문서이고 A문서가 정형 데이터라 필요 없음.
- 여러 파일 일괄 처리 — 한 번에 한 건만 쓴다.
- 여러 사용자 지원, 배포, 설치 프로그램 — 본인만 쓴다.
- A문서 내용의 정확성 검증(분류가 맞는지 등) — 프로그램은 옮기기만 한다.
- 그 밖에 제외할 것 — TBD, 사용자 확인 필요(영문판 등).

## Open Questions
- [ ] 원본 .hwp 파일 — 사용자가 나중에 전달 예정. 받기 전에는 양식을 PDF만 보고 만들어야 한다.
- [ ] 같은 제품의 A·B 쌍(비교 기준) — 아직 없음. 사용자가 나중에 전달 예정. 받기 전에는 "정답"과 비교할 수 없다.
- [ ] B 양식에 칸은 있는데 A문서에 대응하는 항목이 아예 없는 곳(예: 우측 상단 MSDS 번호 칸, 머리글의 버전·날짜, 공급자 "구분")은 비워 두는가, 칸 자체를 빼는가? — 원본 양식 수령 후 칸 목록을 만들어 확인
- [ ] 그림문자 — A문서에는 이미지로 들어 있는 것으로 보인다. 그대로 옮기는가, 분류에 맞춰 새로 넣는가?
- [ ] A문서 형식이 "비슷하다"의 범위 — 항목 순서나 이름이 얼마나 달라질 수 있는가? 다른 예시 파일이 필요하다.
- [ ] 이 맥에서 Word 문서를 PDF로 자동 변환할 수 있는가? — 아직 실행해 보지 않음.
- [ ] 결과물을 PDF로 만들기 전에 사람이 손으로 고칠 수 있어야 하는가?
